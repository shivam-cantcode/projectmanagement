Project Management Backend

A backend API for managing projects, teams, and tasks with authentication and role-based access control.

🚀 Features
User Authentication (JWT)
Project & Task Management
Team Collaboration
Role-Based Access
RESTful APIs
MongoDB Integration

🛠️ Tech Stack
Node.js
Express.js
MongoDB
Mongoose
JWT

⚙️ Installation
git clone https://github.com/shivam-cantcode/projectmanagement-backend.git
cd projectmanagement-backend
npm install
npm run dev

🔑 Environment Variables
PORT=8000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret

📌 API Routes
/api/auth
/api/projects
/api/tasks
